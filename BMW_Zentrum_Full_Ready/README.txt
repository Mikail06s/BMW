BMW ZENTRUM — ГОТОВЫЙ САЙТ

ЗАПУСК:
1. Распакуй ZIP целиком.
2. Открой папку bmw_zhilina_site в PyCharm.
3. Открой Terminal в корне проекта.
4. Выполни: python -m http.server 8000
5. Открой в браузере: http://localhost:8000

ФОТОГРАФИИ:
Скопируй свои JPG-файлы в папку assets и назови их согласно файлу assets/ПОЛОЖИ_СЮДА_ФОТО.txt.
Весь CSS уже подключён, редактировать его не нужно.

ВАЖНО:
Регистрация и вход работают демонстрационно через localStorage браузера. Это учебный вариант без сервера и базы данных; не используй настоящие пароли. Форма контактов демонстрационная и не отправляет письма.
